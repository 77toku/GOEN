# GOEN v2

GitHub Pagesにそのまま公開できる静的サイトです。

## 更新方法
1. このZIPを解凍
2. GitHubの `77toku/GOEN` リポジトリを開く
3. 現在のファイルをバックアップ
4. ZIP内のファイルをリポジトリ直下へアップロード
5. Commit changes
6. 数分後に `https://77toku.github.io/GOEN/` を再読み込み
